# 記事の出典記録

対象は `content/ranking/index.md`、`content/guide/index.md`、`content/posts/alpha-mai-osusume.md` の3記事です。2026年9月18日に公的機関とメーカーの公開ページを取得し、本文と比較表を確認しました。

## 保存内容

- `ledger.json`：出典番号・URL・確認に使った短い引用。
- `retrieval.json`：HTTPステータス、最終URL、確認日時、取得レスポンスと抜粋ファイルのSHA-256。
- `excerpts/01.txt`～`12.txt`：主張を確認するために必要な箇所だけを抜粋。`[別抜粋]`は連続していない箇所の境界です。
- `verify.py`：台帳と引用の整合、抜粋ハッシュ、出典一覧、主要仕様表、人数・日数の計算を検査するスクリプト。

商品ページの「5年保存」「そのまま食べられる」は画像代替テキストにも記載されているため、該当する短いHTMLタグを保存しています。商品画像と全文HTMLは同梱していません。

このディレクトリはHugoの公開出力には含まれません。ただし、このGitHubリポジトリ自体は公開されています。

## 再検証

リポジトリ直下で実行します。Pythonの標準ライブラリのみを使用します。

```sh
python3 docs/sources/verify.py
npm test
```

出典番号は3記事共通です。個々の記事では番号が飛びますが、記事内で引用した番号とSources一覧を一致させています。スクリプトは全記事の引用集合と台帳集合の一致も検査します。

検査は、保存した情報と記事の整合性を確認するものです。メーカーの最新ページを再取得した証明や、解釈が正しいことの自動判定にはなりません。仕様の更新時には一次情報を再確認し、本文・抜粋・台帳・検証条件をまとめて更新してください。

## 確認対象と限界

- アルファ米は尾西の通常100gタイプ3品に限定し、別シリーズの仕様を混ぜていません。
- 「5年保存」は各商品ページの表示です。公式FAQの一般説明を使って購入後の残存期限を推定していません。
- 商品情報は確認日現在のものです。価格・販売実績・人気順位・実食結果・到着個体の期限は調査対象外です。
- 献立の記入例や主食の合計カロリーは、個人の必要栄養量を満たす完成メニューではありません。
- 保管条件、原材料、アレルギー表示は、購入する現物の表示を優先します。
- 内容検証、画面検証、Cloudflare Pagesでの公開確認は別の検証です。
