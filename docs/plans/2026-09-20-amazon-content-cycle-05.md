# 記事追加とAmazon提携準備（サイクル05）

## 目的と現状

家庭備蓄の「量と商品を選んだ後」に残る問いを補い、読者に役立つ公開記事を10本以上そろえて、既存もしも経由のAmazon提携条件を再評価する。10本は審査の入口であり、承認・集客・収益の保証ではない。既存の基本ガイド、用途比較、アルファ米、セット、おかずの5記事を分母の基準として保持する。

依頼範囲：非常食ナビの記事追加とAmazon提携取得に向けた作業。対象は既存のもしも媒体のみ。無料・既存アカウント内、既存PR/CI/公開検証の手順を使う。有料契約、新規アカウント、本人確認、支払情報、別媒体、新解析は対象外。人による校正・事実確認と必要な本人宣言をAIの独立レビューで代用しない。

## 受入と停止条件

1. 一次情報、命題マッピング、数値検算、記事間整合。引用番号は監査データに持ち、読者向けの参考欄へ出す。
2. 承認済みデザインで太字＋黄色マーカー、必要な比較表、具体的次行動。一般写真を商品現物・実食の証拠にしない。
3. 通常buildとdraft buildの分離、一覧・sitemap・内部リンク、320/390/PC、既存機能回帰、解析への入力不送信。
4. 必須独立レビューを2文脈で実施：編集/根拠/安全/Purpose-Fit、技術/表示/漏洩/Risk/Simplicity。原稿とデータの同じ凍結snapshotへ結び付ける。
5. 人による校正・事実確認を実際の原稿版に記録。その後に公開・公開数確認・現行Amazon条件/媒体状態のread-back・申請。申請先で新しい規約同意/本人宣言が必要なら停止し、該当文言を提示する。

食品安全の根拠不足、画像権利/商品違い、媒体否認/提携終了、必要な校正なし、ログイン失効、独立review BLOCKは該当工程を停止。ログイン失効だけならローカル原稿の制作は続行できる。
