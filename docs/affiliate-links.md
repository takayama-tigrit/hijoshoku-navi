# 楽天市場への広告リンク

## 実装

- `data/affiliate-links.json` に、対象媒体向けに「どこでもリンク」のテキストリンク生成画面から取得した公開URLを保存する。ログイン情報・APIキーではない。
- `rakuten-search` shortcodeは固定の商品検索語を参照する。入力欄・メモ・訪問者ID・任意のURLパラメータを取り込まない。
- 既存の通販検索導線10箇所を楽天市場へ置換する。検索語は9種類。メーカー公式の仕様リンク、数量、比較、在庫メモは変更しない。
- 広告を含む4記事ではタイトル付近に広告表示を出す。`rel="sponsored nofollow"`、`referrerpolicy="origin"`を付け、送信元URLのパス・queryを広告リンク先へ渡さない。
- 配布コードのうちリンクURLだけを使用する。表示計測pixel、広告主スクリプト、Attribution Reporting属性は追加しない。したがってASPインプレッション数の計測は検証対象外。GA4の導入・設定・独自イベントは変更しない。
- `enabled`、Hugoの`baseURL`、Cloudflareの`CF_PAGES_BRANCH`を確認する。異なるbaseURL、Cloudflareの非mainブランチ、`enabled=false`では通常の楽天検索リンクへ戻す。別媒体への転用時には、その媒体の登録・提携とコード取得を別途行う。mainの配信エイリアスは同じビルドを使うため、この判定はブラウザの実行時origin制限ではない。

## 公式条件の根拠

確認日：2026-09-20。

- [もしもFAQ](https://af.moshimo.com/af/shop/help)：媒体が「審査中」でもリンク掲載可能。登録削除時にはリンクが無効になる。媒体審査の完了と広告主との提携は別の状態。
- 同FAQ「取得したアフィリエイトタグを書き換えても違反にはなりませんか」：URLのみの利用でも成果発生には問題ないが、インプレッションが正常に計測されない等の注意がある。
- 同FAQ「アフィリエイトリンクが正しく遷移するか確認するには」：クリックだけであれば可能。Cookieの影響を残さないよう、独立したプライベートコンテキストで確認し、購入しない。
- [楽天プロモーション詳細](https://af.moshimo.com/af/shop/promotion/detail?promotion_id=54)・[楽天の注意事項](https://af.moshimo.com/af/shop/support/rakutenNotice)：本人申込NG、提携対象メディア限定。不正クリック誘発、強制リダイレクト、レビューの転載などは禁止。

生成画面で9検索先のドメイン検証を通過したURLを使用する。ドメイン検証は各販売店の在庫・配送・商品一致・成果帰属を保証するものではない。リンク名は「検索」とし、読者が商品名・容量・入数を確認できる既存の案内を保つ。

## 検証と停止

```sh
node tests/affiliate-links.spec.mjs
npm test
```

ブラウザ検証は外部通信を遮断したローカルfixture。PC/SP/JS無効でリンクの固定値・広告表示・無断外部送信なし・通常リンクfallbackを検証する。Googleの実受信・ASPクリック集計・報酬を証明するテストではない。

公開時は対象commitのCI・Cloudflare配信・独自ドメインのHTMLを確認し、必要最小回数だけプライベートコンテキストで実リンク遷移を確認する。自己QAを顧客送客・収益と混ぜない。提携終了や媒体登録削除が判明したら`enabled=false`にして通常リンクへ戻し、同じ公開検証を行う。直前の正常commitへのrevertも復旧経路とする。
